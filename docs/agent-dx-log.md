# エージェント向け DX の記録

CLI の使い方を変えたら、コーディングエージェントに同じタスクを解かせ、変える前と比べます。エージェント自身の報告では採点せず、できたファイルをスクリプトで確かめます。

## 測り方

```bash
vp run -r build
(cd apps/cli && pnpm pack --pack-destination ../../tmp/packs)
node scripts/agent-dx/run.ts --tarball tmp/packs/loopcraft-0.2.0.tgz --label after --runs 5
```

- `--label` ごとに `tmp/agent-dx/<label>/` を作り、パックした CLI を入れた空のディレクトリで `claude -p` を走らせます。手元の設定・MCP サーバー・`serve`（ブラウザを開いて終わらない）は使わせません。
- タスクは `scripts/agent-dx/tasks.ts` にあります。採点は `scripts/agent-dx/score.ts` で、比べる CLI の版によって基準が動かないよう、`@loopcraft/core` は使いません。
  - **create**: 文章から図を作る。変数どうしが重ならず、矢印が変数を突き抜けない配置にする
  - **extend**: 既にある図に変数と関連を足し、できたループに注目する。ほかは変えない
  - **tidy**: 変数が重なった図の配置を直す。構造は変えない
- 結果は `results.jsonl` に 1 回ずつ追記し、最後に表を出します。数えるのは、成功した回数・ターン数・コスト・出力トークン・Bash の呼び出し・loopcraft の呼び出し・`--help` を読んだ回数・スクリプトを書いた回数です。

## 2026-10-18: 早見表・JSON の形・check / edit / layout / render / diff

### Experiment

- 比べたもの: `baseline`（0.2.0。#21 をマージした時点）と `after`（下の Changes を入れ、レビューで直す前の版）。
- 条件: Sonnet、各タスク 5 回。
- 最初の基準値は、プラグインの進捗表示ツールが混ざったため取り直しました（`baseline2`）。

### Findings

15 回の合計で見ると、次のように変わりました。

|                                   | 前    | 後    |
| --------------------------------- | ----- | ----- |
| ターン                            | 5.7   | 4.4   |
| コスト                            | $1.20 | $0.97 |
| 時間                              | 40 秒 | 26 秒 |
| 出力トークン                      | 2393  | 1426  |
| --help を読んだ回数（1 回あたり） | 1.7   | 1.0   |

- **正しさは前から変わらない。** 前の CLI でも 15/15 で成功しました。Sonnet なら、座標を自分で考えれば重ならない図は書けます。差が出たのは、そこまでの手間です。
- **前の CLI で配置を直すとき、エージェントは CLI の外を探っていた。** `tidy` では変数の大きさを知る手段がありませんでした。そのため、同梱したエディタの圧縮済み JS を grep して `NODE_` などの定数を探し、Python で座標を書き換えていました。結果は「画面で確かめてはいません」と添えて終わっていました。
- **後の CLI では 1 回の呼び出しで済んだ。** `layout --all && check --format json && diff` を 1 回の Bash で打ち、崩れが無いことを CLI の判定で確かめて終えました。`create` では、早見表の heredoc をそのまま写して `edit` に操作を渡していました。`render -o diagram.png` で画像を作って Read で見た回もありました（create で 1/5、tidy で 3/5）。
- **--help を読むのは 1 回で済むようになった。** 先頭の早見表だけで足り、`schema` や各コマンドの `--help` は読みませんでした。

### Changes

- `--help` の早見表、`--format json` の `{ok,data}` / `{ok:false,error}`、`check` `edit` `layout` `render` `diff` `agent-init` を足しました。position を省けるようにしました。
- 測った後に、レビューで見つかった誤った成功と誤った案内を直しました。そのため、表の「後」は直す前の版の値です。

### 次に測ること

- 前の CLI でも全部成功したので、タスクが易しすぎます。変数が 15 個を超える図や、既にある配置を崩さずに足すタスクで差を見ます。
- `agent-init` で AGENTS.md に方針を書いた条件と、タスクの文で loopcraft を名指ししない条件を比べます。
- Sonnet より小さいモデルでも比べます。
