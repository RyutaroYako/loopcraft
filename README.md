# Loopcraft

システム思考で使う因果ループ図（システム図）を描くための、ブラウザだけで動くエディタです。

出来事どうしを矢印でつなぐと、図の中にあるループを自動で見つけ、自己強化ループ（R）かバランスループ（B）かを判定します。どのループを図の主張として見せるかは、自分で選べます。

## 主な機能

- 出来事と、その間の因果関係（同じ向きに動く `+` / 逆向きに動く `−`）、遅れの描画
- ループの自動検出と、R / B の判定
- 見せたいループを選び、名前や説明を付ける
- JSON での書き出し・読み込み
- ブラウザへの自動保存、元に戻す / やり直す、キーボードでの操作

## 使い方

キャンバスをダブルクリックすると出来事を追加できます。出来事の右端にある点をドラッグすると矢印を引けます。矢印の `+` / `−` をクリックすると、向きが切り替わります。

まずは空の画面にある「サンプルを開く」から試してみてください。

## データ形式

保存する JSON の形式は [`public/system-diagram.schema.json`](public/system-diagram.schema.json) の JSON Schema で定義しています。このスキーマは `src/model/schema.ts`（valibot）から生成したものです。

## 開発

[Vite+](https://viteplus.dev/)、SolidJS 2、valibot で作っています。

```bash
vp install         # 依存関係のインストール
vp dev             # 開発サーバー
vp check           # フォーマット・lint・型チェック
vp test            # テスト
vp build           # 本番ビルド
vp run gen:schema  # JSON Schema の再生成
```
