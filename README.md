# System Diagram Editor

システム思考のシステム図（因果ループ図）をブラウザだけで編集するエディタ。

## できること

- 出来事（変数）を置き、因果の矢印（`+` 同じ向き / `−` 逆向き、遅れの有無）でつなぐ
- ループを自動で検出し、`−` の数から自己強化（R）かバランス（B）かを判定する
- 検出したループから、図の主張にしたいものを「見出す」（名前・説明・記号の位置を付けられる）
- JSON の書き出し・読み込み（ドラッグ＆ドロップ可）。読み込み時はスキーマと参照整合性を検証する
- ブラウザへの自動保存、元に戻す / やり直す

## 操作

| 操作                | 方法                                                                                                             |
| ------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 出来事を追加        | キャンバスをダブルクリック                                                                                       |
| 関連を引く          | 出来事の右端の点をドラッグ（少し離れた空白で離すと新しい出来事を作る）／検査パネルの「原因を追加」「結果を追加」 |
| 極性を切り替え      | 矢印の `+` / `−` をクリック                                                                                      |
| 曲がり具合          | 選択した矢印の中点をドラッグ（ダブルクリックで戻す）                                                             |
| 名前を変える        | 出来事をダブルクリック、選択して Enter、またはフォーカスして F2                                                  |
| 移動                | ドラッグ、またはフォーカスして矢印キー（Shift で大きく）                                                         |
| 削除                | Delete / Backspace                                                                                               |
| 元に戻す / やり直す | Ctrl(⌘)+Z / Ctrl(⌘)+Shift+Z（Ctrl+Y でもやり直せる）                                                             |
| 書き出す            | Ctrl(⌘)+S                                                                                                        |
| 表示                | ホイールで移動、Ctrl(⌘)+ホイールで拡大縮小、背景ドラッグで移動                                                   |

## 開発

```bash
vp install
vp dev             # 開発サーバー
vp check           # フォーマット・lint・型チェック
vp test            # テスト
vp build           # 本番ビルド
vp run gen:schema  # src/model/schema.ts から public/system-diagram.schema.json を再生成
```

## データモデル（`src/model/`）

| ファイル         | 内容                                                           |
| ---------------- | -------------------------------------------------------------- |
| `schema.ts`      | valibot スキーマと型。`DiagramSchema` は参照整合性まで検証する |
| `integrity.ts`   | ID 重複・参照切れ・自己ループ・閉じていないループなどの検出    |
| `loop.ts`        | ループの種類（自己強化/バランス）の導出、閉路の正規化キー      |
| `cycles.ts`      | Johnson のアルゴリズムによるループの列挙                       |
| `edit.ts`        | 図を編集する純粋関数（削除は関連・ループへ連鎖する）           |
| `geometry.ts`    | 出来事の大きさ、曲線の矢印、ループ記号の位置の計算             |
| `io.ts`          | JSON の読み込み・書き出し                                      |
| `json-schema.ts` | 保存形式の JSON Schema 生成                                    |
